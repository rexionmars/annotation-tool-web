# ⌨️ Guia Completo de Atalhos de Teclado

## Visão Geral

A ferramenta de anotação web possui atalhos de teclado abrangentes para aumentar sua produtividade. Todos os atalhos funcionam sem necessidade de clicar em botões, permitindo um fluxo de trabalho mais rápido.

---

## 🎨 Modos de Anotação

### Alternar Modo Gordura
- **Tecla**: `F`
- **Descrição**: Ativa o modo de anotação de gordura (cor vermelha)
- **Uso**: Pressione `F` a qualquer momento para mudar para o modo gordura

### Alternar Modo Músculo
- **Tecla**: `M`
- **Descrição**: Ativa o modo de anotação de músculo (cor azul)
- **Uso**: Pressione `M` a qualquer momento para mudar para o modo músculo

---

## ✏️ Controles de Polígono

### Finalizar Polígono
- **Tecla**: `Enter` ou `Return`
- **Descrição**: Completa e salva o polígono atual
- **Requisito**: Mínimo de 3 pontos no polígono
- **Alternativa**: Clique direito do mouse

### Limpar Polígono
- **Tecla**: `Esc` ou `Escape`
- **Descrição**: Remove todos os pontos do polígono em andamento
- **Uso**: Útil quando você quer recomeçar sem finalizar

### Resetar Anotações
- **Tecla**: `R`
- **Descrição**: Remove TODAS as anotações da imagem atual
- **Confirmação**: Mostra diálogo de confirmação antes de executar
- **⚠️ Cuidado**: Esta ação remove polígonos de gordura E músculo

---

## 🧭 Navegação entre Imagens

### Próxima Imagem
- **Tecla**: `→` (Seta Direita) ou `ArrowRight`
- **Descrição**: Avança para a próxima imagem no conjunto
- **Comportamento**: Anotações são preservadas automaticamente

### Imagem Anterior
- **Tecla**: `←` (Seta Esquerda) ou `ArrowLeft`
- **Descrição**: Volta para a imagem anterior no conjunto
- **Comportamento**: Carrega anotações existentes automaticamente

---

## 🔍 Zoom e Visualização

### Zoom In/Out (Mouse)
- **Ação**: `Scroll do Mouse` para cima/baixo
- **Descrição**: Aumenta ou diminui o zoom da imagem
- **Foco**: Zoom ocorre na posição do cursor
- **Alcance**: 50% até 500% (0.5x a 5x)

### Zoom In (Teclado)
- **Tecla**: `Cmd + +` (Mac) ou `Ctrl + +` (Windows/Linux)
- **Descrição**: Aumenta o zoom em 20%
- **Máximo**: 500%

### Zoom Out (Teclado)
- **Tecla**: `Cmd + -` (Mac) ou `Ctrl + -` (Windows/Linux)
- **Descrição**: Diminui o zoom em 20%
- **Mínimo**: 50%

### Resetar Zoom
- **Tecla**: `Cmd + 0` (Mac) ou `Ctrl + 0` (Windows/Linux)
- **Descrição**: Volta ao zoom padrão de 100%
- **Uso**: Útil para reorientar após muito zoom

### Pan/Mover Imagem (Espaço)
- **Tecla**: `Espaço` (segurar) + `Arrastar Mouse`
- **Descrição**: Move a imagem quando está com zoom
- **Cursor**: Muda para ícone de "mão"
- **Comportamento**: Não adiciona pontos ao polígono enquanto ativo

### Pan/Mover Imagem (Mouse)
- **Ação**: `Botão do Meio do Mouse` + `Arrastar`
- **Descrição**: Alternativa para mover a imagem
- **Uso**: Não requer segurar tecla

---

## 💾 Exportação e Salvamento

### Exportar Anotações
- **Tecla**: `Cmd + S` (Mac) ou `Ctrl + S` (Windows/Linux)
- **Descrição**: Exporta todas as anotações em arquivo ZIP
- **Conteúdo**: Máscaras + imagens segmentadas
- **Formato**: `annotations_YYYY-MM-DD.zip`

## 🎯 Fluxos de Trabalho Recomendados

### Fluxo 1: Anotação Rápida
```
1. F → Modo Gordura
2. Cliques para criar polígono
3. Enter → Finalizar
4. M → Modo Músculo
5. Cliques para criar polígono
6. Enter → Finalizar
7. → → Próxima imagem
```

### Fluxo 2: Precisão com Zoom
```
1. Scroll → Aumentar zoom em região específica
2. Espaço + Arrastar → Posicionar
3. F → Modo Gordura
4. Cliques precisos
5. Enter → Finalizar
6. Cmd/Ctrl + 0 → Resetar zoom
7. → → Próxima imagem
```

### Fluxo 3: Correção
```
1. Esc → Limpar polígono incorreto (se em andamento)
   OU
   R → Resetar tudo (se já finalizado)
2. F ou M → Escolher modo
3. Recomeçar anotação
```

## 🖱️ Interação Mouse + Teclado

### Adicionar Pontos
- **Mouse**: Clique esquerdo
- **Teclado**: Não disponível (requer precisão do mouse)

### Finalizar Polígono
- **Mouse**: Clique direito
- **Teclado**: `Enter`

### Navegar com Preview
- **Mouse**: Mover cursor (mostra preview da linha)
- **Teclado + Mouse**: `Espaço` + Arrastar (modo pan)

---

## 📝 Notas Importantes

### Prioridade de Teclas
- Atalhos **não funcionam** quando você está digitando em campos de texto
- `Espaço` ativa modo pan, mas não adiciona pontos ao polígono
- `Cmd/Ctrl` combinações têm prioridade sobre teclas simples

### Compatibilidade
- **Mac**: Use `Cmd` (⌘) em combinações
- **Windows/Linux**: Use `Ctrl` em combinações
- Todos os outros atalhos funcionam igual em todas as plataformas

### Indicadores Visuais
- **Zoom**: Indicador no canto superior esquerdo mostra porcentagem
- **Modo**: Botão do modo ativo fica destacado na sidebar
- **Cursor**: Muda para "mão" em modo pan, "cruz" em modo anotação

---

## 🚀 Dicas de Produtividade

1. **Use atalhos de modo** (`F`/`M`) em vez de clicar nos botões
2. **Zoom com scroll** é mais rápido que botões
3. **`Espaço` + Arrastar** é mais ergonômico que botão do meio
4. **`Enter`** para finalizar é mais rápido que clique direito
5. **`Cmd/Ctrl + S`** frequentemente para não perder trabalho
6. **Setas** (`←`/`→`) mantêm suas mãos no teclado para navegação rápida

## ❓ FAQ

**P: Por que meu atalho não funciona?**
R: Verifique se você não está com foco em um campo de texto. Clique na área do canvas primeiro.

**P: Posso customizar os atalhos?**
R: Não nesta versão, mas está no roadmap futuro.

**P: O zoom está muito sensível/lento**
R: A sensibilidade do scroll depende do seu mouse/trackpad. Use `Cmd/Ctrl + +/-` para controle mais preciso.

**P: Como cancelo uma anotação em andamento?**
R: Pressione `Esc` para limpar os pontos sem finalizar o polígono.
